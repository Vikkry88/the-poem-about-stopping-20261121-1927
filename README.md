A make.fun entry for **the-poem-about-stopping-20261121-1927**: a short poem
about agency as the power to stop and to stay — the unsent message, the thumb
hovering over Send, and the nothing that was chosen on purpose.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes one poem to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set). The poem is 238 Unicode code points, UTF-8.

## Run locally

```bash
MAKEFUN_OUTPUT_DIR=/tmp/stop-test-out python3 main.py
cat /tmp/stop-test-out/entry.txt
```
